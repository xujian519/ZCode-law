# patent-index-asset

随包事实索引（法条 patent-law、费用 patent-fees）共用的 YAML 资产字段格式库。意图：让两个索引共享一套字段规则（必填/可缺省字符串、ISO 日期、正整数、闭集枚举、映射、转录来源），而不是各拷一份。不变量：读取器要么返回资产声明的值，要么通过调用方注入的 `AssetFail` 工厂拒绝整个文件——拒绝强转，错误类型归属调用方（各自子类化 `IndexAssetError` 以便 catch）。纯库：无状态、无副作用、无事件。与其它模块的交集：patent-law / patent-fees（P2 由其它任务迁移）经本模块公开入口消费字段读取器；本模块不依赖任何其它专利域模块。
